# ابزاربوک

## دیپلوی روی Railway

1. این پوشه رو به یک ریپازیتوری گیت‌هاب پوش کن (ریشه ریپو باید همین فایل‌ها باشه، نه داخل یک ساب‌فولدر).
2. توی Railway: New Project → Deploy from GitHub repo → همین ریپو رو انتخاب کن.
3. Railway به‌خاطر وجود `package.json` به‌صورت خودکار Node رو تشخیص می‌ده و با `npm start` سرور رو بالا میاره (پورت از متغیر محیطی `PORT` که خودِ Railway ست می‌کنه خونده می‌شه — نیازی به تنظیم دستی نیست).
4. بعد از دیپلوی موفق، از تب Settings دامنه‌ی سفارشی (`abzarbook.com`) رو وصل کن و رکورد CNAME/TXT که Railway میده رو توی پنل DNS دامنه ست کن.

## ساختار فایل‌ها

- `index.html` — صفحه اصلی (هاب)
- `hoghoogh-dastmazd.html` — ابزار حقوق و دستمزد
- `rahn-vam.html` — ابزار رهن، اجاره و وام
- `text-tools.html` — ابزار متن فارسی
- `vahed.html` — مبدل واحد (طول، وزن، حجم، سطح، سرعت، فشار، دما، زمان)
- `salamat.html` — محاسبه‌گر سلامت (BMI، کالری روزانه، آب بدن)
- `size-chart.html` — مبدل سایز پوشاک و کفش (ایران/اروپا/آمریکا/انگلیس)
- `etebarsanji.html` — اعتبارسنجی شماره شبا و کد ملی
- `server.js` — سرور استاتیک ساده (بدون وابستگی خارجی)
- `robots.txt`, `sitemap.xml` — برای سئو

هیچ بیلد یا دیتابیسی لازم نیست؛ همه محاسبات توی مرورگر کاربر انجام می‌شه.
